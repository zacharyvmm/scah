# Security policy

scah parses untrusted HTML, so crashes, hangs, unbounded memory growth, and
incorrect matching that could bypass filtering are all in scope.

## Reporting a vulnerability

Please don't open a public issue. Email **contact@zacharymm.com** with a
description, a minimal input that reproduces the problem, and the version or
commit you tested.

## Supported versions

scah is pre-1.0. Fixes land on `main` and ship in the next release; older
releases are not patched.
