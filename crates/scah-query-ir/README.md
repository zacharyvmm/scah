# scah-query-ir

The query layer of scah: CSS selector parsing, the query builders, and the compiled `Program` that scah's bitset matcher runs.

**This crate is an implementation detail of [scah](https://crates.io/crates/scah)**
and has no stability guarantees of its own: its API can change in any
release. Use [`scah`](https://crates.io/crates/scah) instead.

See [Architecture](https://github.com/zacharyvmm/scah/blob/main/docs/architecture.md)
for where this crate fits.
